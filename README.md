# Vocab

A personal vocabulary app that takes each word from "I recognise it" to "I can use it
in an essay": spaced repetition (FSRS), exercises graded on what you actually do, and
words you capture from your own reading. Runs on iPhone and PC as an installable web
app that works offline.

- Design: [docs/PLAN.md](docs/PLAN.md)
- Build order and progress: [docs/ROADMAP.md](docs/ROADMAP.md)
- Session log: [docs/LOG.md](docs/LOG.md)
- Hosting setup: [docs/SETUP-CLOUDFLARE.md](docs/SETUP-CLOUDFLARE.md)

## Develop

```
npm install
npm run dev     # local dev server
npm test        # formatting, types, unit tests, end-to-end tests
```
